# 供应链安全

> 本文是 [English](../supply-chain-security.md) 的中文同步版。若中英文在法律、安全、治理或规范性要求上存在冲突，以英文版为准。

本包是私有包，Web 应用尚未消费它。

首次消费端集成前，CI 必须要求：

- 冻结的 pnpm 安装；
- 类型检查及完整测试套件；
- 正确性覆盖率门禁；
- 依赖公告及 OSV 扫描；
- 仅 dist 的包构建；
- 从打包 tarball 安装并导入每个公开入口；
- 验证 tarball 中存在浏览器 Worker；
- 对已提交及下载固定资源验证来源和 SHA-256。

发布、注册表凭据、消费端自动更新和发布 SBOM 均延后，直至包 API 获准供消费端使用。
