# 功能库稳定性门禁

> 本文是 [English](../stabilization-gates.md) 的中文同步版。若中英文在法律、安全、治理或规范性要求上存在冲突，以英文版为准。

当前维护模式仅限本地。这些门禁使用本仓库内的命令、打包产物、固定资源和运行时证据衡量功能库。发布和消费端集成属于独立活动，不决定功能库是否就绪。

1. **本地已通过：** 已完成公开入口名称与可序列化请求/结果契约的 API 审查，见 `architecture/public-api-contract.md`。
2. **本地已通过：** 打包后的浏览器入口能从安装归档解析 Worker，且打包 Worker 已完成一次请求/结果运行时冒烟测试。
3. **本地已通过：** 浏览器执行不会针对不受信任上传静默回退到 CPU 密集型内联工作。Node 或测试所需的内联执行是显式 API。
4. **本地已通过：** 首条认证管线的已提交固定资源、Golden Motion、结构重载、语义比较，以及固定 Blender 5.2.0 LTS / Godot 4.7.1 回执分别通过。Unity 已延期，当前本地认证配置既不要求也不声明 Unity 兼容性。
5. **本地已通过：** 包大小、浏览器入口与 Worker 入口已有受门禁约束的测量基线；公开高层导入、目标检查与求解路径通过 Worker 执行。

当前全部功能库稳定性门禁均在本地通过。证据不完整的单项能力仍可保持实验状态。稳定或认证状态只取决于适用的功能库自有门禁，不得依赖任何特定消费端的构建或部署。
