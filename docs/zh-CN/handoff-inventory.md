## 有意保留在 Web 应用中的内容

- Next.js/Vinext 路由、React 状态、UI 组件、页面布局和预览表现。
- SEO、本地化字符串、分析、内容、市场/目录发布及 Cloudflare 部署。
- 将 SDK 结果转换为用户可见流程的产品编排。
- 消费端特有的发布和运维文档。

预览代码可以消费规范结果，但任何解析、求解、验证、认证或导出模块都不得依赖 React 组件或浏览器场景。

## 临时重复与切换状态

源仓库暂时仍保留现有引擎实现。这是有意安排：只有独立 API 与打包 Worker 契约通过 `stabilization-gates.md` 后才会切换。不存在双向同步脚本；修复必须经审查后有意移植，避免归属重新变得含糊。

`3dretarget-online` 当前没有 `3dretarget` 包依赖，稳定化阶段不得安装。后续必须由独立、明确批准的集成任务锁定版本、替换消费端导入、运行两边门禁并记录回滚证据，之后才能删除重复实现。

1. 本仓库独立运行 `pnpm verify` 通过。
2. 包验证仅发现声明的六个公开入口，归档中没有测试、研究语料或 Web 产品文件。
3. 每个已提交固定资源都具备可复现的来源及完整性证据。
4. 每份规范性英文文档都有中文对应版；法律、安全、治理及规范冲突以英文为准。
5. 消费端在另行批准切换前保持无本包依赖。
