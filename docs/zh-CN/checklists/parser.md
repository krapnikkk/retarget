# 解析器变更检查表

> 本文是 [English](../../checklists/parser.md) 的中文同步版。若中英文在法律、安全、治理或规范性要求上存在冲突，以英文版为准。

- [ ] 仅探测有界字节窗口，使用内容证据而不是文件名。
- [ ] 在分配展开数组前拒绝截断头、无效计数/偏移、非有限数和不受支持的插值。
- [ ] 应用共享的输入、时长、轨道、帧、采样、输出及期限限制。
- [ ] 在返回规范动作前，只执行一次源坐标轴、单位、静止姿势、别名、时间、根运动和四元数连续性规范化。
- [ ] 通过安全注册表解析包路径；拒绝路径穿越、绝对 URL、重复冲突及过度 ZIP 展开。
- [ ] 返回稳定错误码，不泄露原始内容或本机路径。
- [ ] 测试有效、畸形、截断、超限、误导性命名及生态歧义输入。
