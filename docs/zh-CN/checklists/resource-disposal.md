# 浏览器资源释放检查表

> 本文是 [English](../../checklists/resource-disposal.md) 的中文同步版。若中英文在法律、安全、治理或规范性要求上存在冲突，以英文版为准。

- [x] 在成功、失败、取消、组件卸载和已配置期限到期后终止 Worker；忽略过期任务完成消息。
- [x] 选择变化或卸载时撤销对象 URL 和包注册表。
- [x] 释放 Three.js 几何体、材质、纹理、控制器、混合器和渲染器。
- [ ] 移除 window/document/canvas 监听器并断开观察器。
- [x] 取消待执行动画帧，并暂停隐藏、离屏或上下文丢失的预览。
- [ ] 为逐帧骨架数据复用动态 GPU 缓冲区。
- [x] 验证快速 A -> B -> C 选择、路由变化、WebGL 上下文丢失/恢复以及重复导入导出不会增加存活资源。
