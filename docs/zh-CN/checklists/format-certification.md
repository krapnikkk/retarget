# 格式认证检查表

> 本文是 [English](../../checklists/format-certification.md) 的中文同步版。若中英文在法律、安全、治理或规范性要求上存在冲突，以英文版为准。

- [ ] 写明精确的源配置、角色配置、导出格式、版本、固定资源来源及预期坐标/单位/根运动语义。
- [ ] 运行受支持的公开入口 / Worker 路径，而不只查询注册表或调用内部函数。
- [ ] 使用独立解析器重载生成字节并验证结构。
- [ ] 确定性比较世界空间骨骼旋转、Hips 位移、手、脚、时长、帧范围、插值和有限值。
- [ ] 声称兼容时，在具名生态及版本中打开或导入输出；保留证据，或明确记录 `not-run`。
- [ ] 对不可变输入、输出、指标和认证记录做哈希。
- [ ] 仅当所有必需门禁持续通过时标记 `certified`；否则如实使用 `beta`、`experimental` 或不可用。
