# ADR-0002：重定向引擎归属迁移到 `3dretarget`

> 本文是 [English](../../architecture/ADR-0002-package-boundary.md) 的中文同步版。若中英文在法律、安全、治理或规范性要求上存在冲突，以英文版为准。

- 状态：已接受
- 日期：2026-08-14

## 背景

Web 应用目前包含可复用的解析器、导入/导出适配器、骨架模型、求解器、验证、认证及 Worker 执行代码，导致引擎变更及其证明资源被绑定到 Web 发布周期。

## 决策

`3dretarget` 是独立包和独立仓库，负责可复用的重定向代码、测试、语料清单及打包后的 Worker 输出。`3dretarget-online` 仍是 Web 产品；在独立 API、包和正确性门禁稳定前不会安装本包。

这种关系受“共享核心/消费端”模式启发，但包表面、发布门禁、资源及集成流程均针对重定向领域设计，而不是从其他仓库原样复制。

## 后果

- 稳定化期间，两仓库暂时保留实现副本。新的引擎修复应优先在此完成；只有当前 Web 产品仍需要时才有意识地移植。
- 暂不引入消费端同步脚本。
- 后续 ADR 必须批准消费端切换和 Web 副本删除。
