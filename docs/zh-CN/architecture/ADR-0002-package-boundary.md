# ADR-0002：消费者中立的功能库边界

> 本文是 [English](../../architecture/ADR-0002-package-boundary.md) 的中文同步版。若中英文在法律、安全、治理或规范性要求上存在冲突，以英文版为准。

- 状态：已接受
- 日期：2026-08-14

## 背景

可复用重定向行为需要稳定契约、证明资源，以及由领域正确性决定的发布节奏。将这些决策绑定到某个应用，会产生产品专属 API、反向依赖和无法衡量功能库质量的发布门禁。

## 决策

`@krapnik/retarget` 是独立、消费者中立的功能库，负责可复用重定向代码、公开契约、测试、语料清单和打包后的运行时产物。

路线图由可复用能力及其证据驱动。只有下游需求无需应用状态、可以通过稳定的平台或可序列化契约表达，并能以合法固定资源和独立验收标准验证时，才属于本库。

任何消费端仓库、应用构建、部署平台或发布周期都不是本库的依赖或就绪门禁。

## 后果

- 消费端锁定功能库版本，并自行负责适配器、集成测试、产品行为、部署和升级时机。
- 本库可以接收消费端提供的真实固定资源，但其来源不会赋予任何消费端优先架构地位。
- 公开兼容性通过版本化契约和本库测试维护，而不是镜像实现或仓库同步。
- 浏览器和 Node 入口是平台表面，不是产品集成。
- 产品 UI、目录、分析、托管及应用专属流程不属于本包。
