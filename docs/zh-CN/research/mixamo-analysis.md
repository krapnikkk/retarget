# Mixamo 分析

> 本文是 [English](../../research/mixamo-analysis.md) 的中文同步版。本文是非规范性研究快照，产品与条款可能变化；冲突时以英文版和 Adobe 当前资料为准。

## 概览

[Mixamo](https://www.mixamo.com/) 是 Adobe 的浏览器 3D 角色自动绑定和动画服务，其核心价值是把困难的角色动画管线压缩为短 Web 流程：

```txt
上传或选择人形角色
-> 自动绑定
-> 选择动画
-> 预览
-> 下载
```

它尤其适合原型、独立游戏、教育、Web 角色实验，以及无需搭建完整 Blender、Maya、Unity 或 Unreal 动画管线就想获得可用人形动作的创作者。

资料：

- Adobe Help：[上传并绑定 3D 角色](https://helpx.adobe.com/creative-cloud/help/mixamo-rigging-animation.html)
- Adobe Help：[Mixamo FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html)
- Adobe Substance 3D：[Mixamo Blender add-on](https://www.adobe.com/products/substance3d/plugins/mixamo-in-blender.html)

## 产品定位

Mixamo 不是完整 DCC 或动画编辑器，而是提供自动人形绑定、现成角色库、大型动作库、浏览器预览和可下载资产的 Web 服务。其用户承诺是速度：无需手工骨架绑定或权重绘制即可让人形模型运动。

## 主流程

```txt
使用 Adobe ID 登录
-> 上传自定义角色或选择库角色
-> 未绑定模型放置绑定标记
-> 等待自动绑定
-> 应用动画
-> 预览并调整动作
-> 下载输出
```

Adobe 文档说明自定义角色上传支持 FBX、OBJ、ZIP；已绑定角色必须上传 FBX。标记式流程要求用户在手腕、肘、膝和腹股沟等关键点放置标记，确认后运行绑定并返回主界面。

## 核心能力

Mixamo 提供人形角色自动绑定、自动骨架生成、蒙皮权重、Mixamo 骨架映射、动作库浏览、预览、部分动画参数调整及下游工具可用的下载输出。

从产品角度看，动作库与自动绑定器同样重要。用户不只在解决“怎样绑定模型”，也在解决“怎样快速获得可用人形动画”。

## 技术特征

公开文档将其描述为使用机器学习自动化角色动画工作的 Web 3D 服务。可观察管线可概括为：

```txt
人形网格检测
-> 标记引导的身体地标对齐
-> 插入骨架
-> 生成蒙皮权重
-> 重定向动画到已生成/识别骨架
-> 导出
```

精确实现并未公开，但产品行为显示其围绕人形身体结构及 Mixamo 自身动画/骨架约定优化。

## 产品边界

- 自动绑定器和动画库面向双足人形，非人形不是一等目标。
- 翅膀、尾巴、额外肢体、大型道具、大片头发或复杂服装可能失败。
- 角色应采用中性/默认姿势，位于世界原点，文件不应包含无关场景对象、摄像机或辅助对象；干净网格更可靠。
- Adobe 还说明只保存最近使用的角色，因此用户应在本地保存绑定结果。

## 账户、费用与可用性

Adobe FAQ 称 Mixamo 对任何 Adobe ID 用户免费，无需 Creative Cloud 订阅。Enterprise 和 Federated ID 不受支持；中国国家代码用户不受支持，因为 Creative Cloud 中国版本不包含这些 Web 服务。

FAQ 还说明 Mixamo 角色和动画可免版税用于个人、商业和非营利项目，包括插图、3D 打印、电影和游戏。具体权利应以 Adobe 当前条款为准。

## 成功原因

Mixamo 的成功来自范围精准，而非通用性：上传到动作的路径短、无需本地软件、无需手工骨骼命名或权重绘制、即时预览、大型可搜索动作库，并能输出给游戏引擎和 3D 工具。服务聚焦常见的常规比例双足人形。

## 弱点

- 不适合任意骨架及动物、生物、多肢、尾巴、翅膀、特殊比例角色。
- 没有现代 VRM/VRMA 优先流程，编辑深度有限。
- 缺乏高级脚锁定/地面接触修正，批处理、项目管理和上传历史也有限。
- 流程依赖 Adobe 账户可用性；专业生产通常仍需在 Blender、Maya、Unity、Unreal 等工具中清理输出。

## 与 3dretarget-online 的关系

Mixamo 既是用户意图来源，也是动作资产来源。`3dretarget-online` 的首要机会并非重做自动绑定器，而是：

```txt
Mixamo FBX 动作
-> 浏览器重定向
-> VRM 预览
-> VRMA 导出
```

这与 Mixamo 互补，因为后者没有一等的 VRM/VRMA 流程。

## 产品经验

- 选择狭窄转换闭环并做到快速。
- 用用户熟悉的格式命名产品，而非抽象重定向理论。
- 把预览成功和导出成功作为核心指标。
- 在求解器与映射 UX 足以支撑前，不声称通用骨架支持。
- 将 Mixamo 作为早期用户熟悉的输入来源。

当前 MVP 的最强定位是：

```txt
Mixamo 是用户获取人形动作的地方。
3dretarget-online 是用户把这些动作转换为 VRM/VRMA 的地方。
```

这让产品足够具体、可以交付，同时为后续通用重定向保留扩展空间。
