# 文档地图

> 本文是 [English](../README.md) 的中文同步版。若中英文在法律、安全、治理或规范性要求上存在冲突，以英文版为准。

本目录记录功能库契约、证据和维护规则：

- `architecture/` 定义稳定的处理与包契约。
- `checklists/` 定义解析器、认证和资源审查门禁。
- 语料文档定义可复现的测试资源和许可证边界。
- `stabilization-gates.md` 记录功能库的本地就绪证据。

产品策略、应用集成、托管和部署文档不属于本仓库范围。

本目录按英文文档树提供简体中文镜像。机器生成的 JSON 锁及第三方许可证不翻译。
