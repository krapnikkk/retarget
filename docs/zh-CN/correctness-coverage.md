# 正确性覆盖率门禁

> 本文是 [English](../correctness-coverage.md) 的中文同步版。若中英文在法律、安全、治理或规范性要求上存在冲突，以英文版为准。

`pnpm verify` 会运行 `pnpm test:correctness-coverage`，以 V8 覆盖率一次性执行 `unit` 和 `slow` 测试项目。覆盖率范围限于解析器、源规范化、姿势采样、目标绑定、绑定及非人形求解器等可能改变导出动作的模块。

门禁是宽松的全局下限（语句、函数、行 75%，分支 60%），用于发现大块未测试的新增代码。它不是单文件棘轮，也不是完整正确性的声明；删除已覆盖代码的重构不应因此失败。

覆盖率与针对四元数归一化、坐标符号、CUBICSPLINE 值选择及根缩放的变异守卫配套使用。百分比增加不能替代这些行为专用测试。
