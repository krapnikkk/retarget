# 正确性覆盖率门禁

> 本文是 [English](../correctness-coverage.md) 的中文同步版。若中英文在法律、安全、治理或规范性要求上存在冲突，以英文版为准。

本地 pre-commit 门禁与不可变发布准备会运行 `pnpm test:correctness-coverage`，可选托管 CI 可以重复执行。门禁覆盖解析器、源规范化、姿势采样、目标绑定和非人形求解器模块，这些模块的变异可能改变导出动作。

阈值是只升不降的棘轮，并非完整正确性的声明。它们锁定当前已证明基线，只能提高。长期分支目标如下：

| 风险面 | 当前分支门禁 | 目标 |
|---|---:|---:|
| Rig Motion glTF 导入器 | 71% | 90% |
| 姿势采样器 | 66% | 90% |
| 源规范化 | 82% | 90% |
| 目标绑定 | 47% | 95% |
| 非人形求解器 | 55% | 90% |

覆盖率与针对四元数归一化、坐标符号、CUBICSPLINE 值选择及根缩放的变异守卫配套使用。百分比增加不能替代这些行为专用测试。
